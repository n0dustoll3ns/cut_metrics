Дизайн-система — этап 1 из проекта

«Ты не толстеешь и не худеешь. Ты просто теряешь время, гадая по весам.»

Дизайн Cut Metrics строится вокруг одной идеи: отделить сигнал от шума. Ниже — токены и компоненты, которые будут применяться на всех экранах приложения.

Сигнатурный мотив: облако разрозненных точек (шум) и одна уверенная линия сквозь него (тренд). Используется на иконке, в онбординге и на карточке саммари.

01

Шесть именованных значений из ТЗ — без добавления новых брендовых оттенков. Cobalt используется точечно, только там, где нужно сказать «этому выводу можно доверять».

Нейтральные тона выше — не новые брендовые цвета, а промежуточные шаги между Instrument Grey и белым/Deep Ink. Нужны для карточек, границ и M3-слоя (surface / surface-container / outline), поверх которого стоит кастомный брендовый слой.

Примечание по контрасту: Steady Green и Alert Rust не используются как сплошная заливка с белым текстом — на белом/светлом Steady Green даёт контраст ≈3.4:1, что не проходит AA для текста. Поэтому статус кодируется точкой-индикатором + текстом Deep Ink на бледной подложке (см. раздел «Компоненты» → бейджи) — это ещё и точнее попадает в тон «показания прибора», чем закрашенная плашка.

03

Сигнатурный элемент

Единственное место, где дизайну разрешено быть выразительным. Три версии — под три контекста использования из ТЗ. Ниже — рабочий тумблер, который наглядно показывает главный принцип продукта.

Иконка приложения
Тёмный Deep Ink как «дисплей прибора». Минимум точек, толстая линия — читается на маленьком размере.
Онбординг
Больше точек — история «до/после» рассказывается на 2–3 экранах: шум → сглаживание → одна линия.
Метка на карточке саммари
Компактная горизонтальная версия — служит визуальным якорем рядом с заголовком отчёта.
