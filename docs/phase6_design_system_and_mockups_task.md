## 1. Контекст и цель

Фаза 6 «Стабилизация и полировка» закрывает баги из отчёта и добавляет: кеш подтверждений
«Ок/Не ок», отображение и выбор источника данных Health Connect, светлую/тёмную/системную
тему, новый формат дат на графиках. Все четыре пункта меняют визуальный язык, поэтому
порядок строгий: сначала дизайн-система, потом макеты, потом код (задание №2).

## 2. Скоуп

Правятся два файла:

- `docs/design-system.html` — тёмная палитра, паттерн «ось дат», бедж с именем источника.
- `docs/screen-today-graph-summary-settings.html` — карточки метрик в новых состояниях,
  ось дат на «Сегодня» и «Тренде», блоки «Тема» и «Источники данных» в «Настройках»,
  новый подэкран выбора источника, тёмный вариант одного фрейма.

Вне скоупа: `screen-onboarding.html` и `screen-paywall.html` (не трогать), светлая
палитра, шрифты, радиусы и сетка отступов — не меняются, новые роли цветов не добавляются.

## 3. Зафиксированные решения пользователя (2026-09-02)

1. Тёмная тема — «приборная» тёмно-серая: фон ≈ `#101214`, карточки чуть светлее фона,
   Deep Ink инвертируется в светлый текст. Инструментальный характер сохраняется.
2. Кеш «Ок» — на пару (метрика + приложение-источник): подтвердили — для этого источника
   больше не спрашиваем; появился новый источник — спросит снова.
3. «Не ок» — сразу постоянный отказ источника для метрики: каждый новый день — ручной
   ввод. Решение меняется и в «Настройках», и в карточке метрики.
4. Выбор источника — один источник на метрику из списка найденных (без сортировки).
5. Охват — вес и шаги (сон read-only, без карточек). Дефолт — «Авто».
6. Формат дат на графике — предложение агента (раздел 5) принимается к макетированию.

## 4. Тёмная тема: токены

Принципы:

- Светлая тема остаётся базовой. Тёмная — производная: те же роли, инвертированные
  значения. Новых ролей/токенов НЕ добавляется.
- Брендовые цвета (signal/steady/alert) в тёмной осветляются до контраста AA на тёмном.

## 5. Паттерн «Ось дат графика» (вес + EMA)

Проблема: сегодня метка «12.8» рисуется для каждой из 30 точек (`interval: 1`) —
«смазывается» (пункт отчёта). Решение зафиксировано в `test_report_26-09-02.md`:

1. Обычный день — только число («7»). Space Mono 10px, Noise Grey.
2. Граница месяца — «1 АВГ»: число + 3-буквенный месяц uppercase, Ink Muted, Space Mono.
   Метка месяца показывается **всегда**, даже если не попадает в шаг прореживания —
   вытесняет ближайшую обычную метку.
3. Прореживание: ≤8 меток на ширину графика (шаг = ceil(точек / 7)).
4. Граница месяца подсвечивается тонкой вертикальной линией сетки (outline, 1px).
5. Тултип по тапу — полная дата «17 июл» + значение.

В `design-system.html` — образец оси (3–4 недели с границей месяца внутри) в секцию
«Компоненты». Применяется на «Сегодня» (30 дн) и «Тренде» (7/30/90 дн).

## 7. Карточка метрики: новые состояния

Контракт данных (детали — задание №2): `SourceSelection` («Авто» | приложение) на
метрику + `ConfirmDecision` («спрашивать» | «доверяем» | «отклонён») на пару
(метрика, источник).

| Состояние | Условие | Вид |
|---|---|---|
| loading | загрузка | как сейчас |
| missing | нет пригодных данных | как сейчас («Ввести») |
| autoUnconfirmed | решение «спрашивать» | как сейчас: значение + бедж + крупные «Ок» / «Не ок» |
| autoConfirmed | «доверяем» ИЛИ источник выбран явно | компакт: значение + строка «Подтверждено · Google Fit» (steady-точка, caption) + иконка «⋯» |
| sourceRefused | все доступные источники «отклонены» | режим ручного ввода по умолчанию + caption «Источник отклонён · введите значение» + иконка «⋯» |
| manualEntryActive | ввод (из missing / после «Не ок») | как сейчас |
| manualConfirmed | Tier 1 ручная запись | как сейчас: значение + «Ручной ввод» + «Отменить» |

Меню «⋯» (в autoConfirmed и sourceRefused): «Доверять этому источнику» / «Отклонить
источник (вводить вручную)» / «Настроить источники…» (переход в Настройки).

«Не ок» из autoUnconfirmed: фиксирует отказ (снекбар «Данные <имя> больше не
используются — изменить можно в Настройках») и сразу открывает ввод — визуально
manualEntryActive с caption'ом как у sourceRefused.

В макете «Сегодня» отобразить: вес — autoConfirmed, шаги — autoUnconfirmed; состояние
sourceRefused — третьей карточкой рядом в аннотациях.

## 8. Настройки: блоки «Тема» и «Источники данных»

**Блок «Тема»** (первый блок экрана):

- Сегмент-контрол из 3: Системная · Светлая · Тёмная. Выбрано по умолчанию — Системная.
- Caption: «Тёмная включается вместе с системной».

**Блок «Источники данных Health Connect»**:

- Строки «Вес» и «Шаги»: справа текущее значение («Авто» или имя приложения), шеврон.
- Тап → подэкран «Источник: Вес» / «Источник: Шаги»:
  - Радио-список: «Авто — приложение выбирает источник само» + найденные приложения
    (имя, package мелко, статус решения: Доверяем / Отклонён / Спрашивает).
  - Отклонённый источник выбрать нельзя — сначала сбросить решение (действие «⋯»
    в строке: «Сбросить решение»).
  - Выбор источника = доверие: карточка метрики больше не спрашивает «Ок/Не ок».

Макет: подэкран — отдельный phone-frame рядом с «Настройками». Плюс минимум один
фрейм «Сегодня» в тёмной версии (сверка с кодом по D.1 задания №2).
