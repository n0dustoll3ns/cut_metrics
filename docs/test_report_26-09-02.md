# Сегодня

## Вес
- Кнопка "Ок" при загруженном значении с сервиса Health ничего не меняет
- Кнопка "Не ок" дает ввести значение и далее тап по галочке тоже ничего не меняет
- Даты на графике смазываются. Предложи вариант как выводить их в формате. Большая часть дат будет просто цифрой. Где идет граница месяца - как-то это показывать, посмотри как будет лучше сделать учитывая текущую дизайн систему, запиши туда что придумаешь.

## Шаги
- Не отображаются шаги загруженниые из сервиса Health
- Дает ввести значение вручную. Если окнуть введенное значение - выводит значение подгруженное из Hеalth


## Вес и шаги - общее
- не показывает конкретный источник сервиса Health, откуда были взяты данные
- нет возможности выбрать конкретный источник сервиса Health, который ответственен за данные.
- не понятно, есть ли локальное кеширование указанных пользователем ответов ок или не ок на работу с данными из health
- Если пользователь ранее указал Ок на данные, полученные из сервиса Health, то надо это закешировать и больше не спрашивать так крупно. На будущее надо где-то nдобавить возможность это решение изменить, при отказе от данные сервиса Health надо запросить ручной ввод и вести по пути, в котором пользователь сам вносит данные.
