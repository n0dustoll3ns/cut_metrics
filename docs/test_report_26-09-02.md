## Решение по датам на графике (зафиксировано 2026-09-02, Фаза 6)

Причина «смазывания»: сейчас метка `12.8` рисуется для **каждой** из 30 точек оси
(`weight_chart.dart`, `interval: 1`). Принятый формат:

- **Обычный день** — только число («7»). Space Mono 10px, Noise Grey.
- **Граница месяца** — «1 АВГ»: число + 3-буквенный месяц uppercase, Ink Muted, Space Mono.
  Метка месяца показывается **всегда**, даже если не попадает в шаг прореживания —
  вытесняет ближайшую обычную метку.
- **Прореживание** — не более ~8 меток на ширину графика (шаг = ceil(точек / 7)).
- Граница месяца дополнительно подсвечивается тонкой вертикальной линией сетки
  (outline, 1px).
- Тултип по тапу — полная дата «17 июл» + значение.

Применяется на «Сегодня» (30 дн) и «Тренде» (7/30/90 дн). Детали макета —
`docs/phase6_design_system_and_mockups_task.md`, §5.
