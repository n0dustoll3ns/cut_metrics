# Product Context — Cut Metrics

## Зачем существует

См. `docs/CutMetrics_biznes_model_i_user_journey.md` для полной картины. Здесь — только то, что
нужно держать в голове при принятии технических решений.

## Бизнес-модель (Freemium)

- **Бесплатно всегда:** сбор данных, графики, сглаженный тренд веса.
- **Платно (подписка):** еженедельное саммари с рекомендацией — единственная платная функция.
- До набора первой базы пользователей — полный доступ бесплатно всем.

⚠️ **Монетизация (AccessGate) сознательно вынесена в отдельную финальную фазу
«Монетизация» — не реализуется в фазах 1–6.** Не добавлять paywall-логику, пока явно
не попросят.

## User journey (кратко)

1. Онбординг: подключение Health Connect → выбор целевого темпа → минимум вопросов.
2. Ежедневно: сглаженный тренд на главном экране, без действий пользователя.
3. Еженедельно: саммари со статусом и рекомендацией.
4. Долгосрочно: ценность растёт с историей данных.

## Дорожная карта фич (относительно текущей реализации)

1. ✅ Сбор данных, графики, тренд — реализовано (alpha).
2. 🔄 Текущая работа — Фаза 6 «Стабилизация и полировка» (багфиксы, кеш подтверждений, источники данных, тёмная тема), см. `activeContext.md` и `progress.md`.
3. ⏸ Открытый вопрос, не блокирует MVP: логика рефидов — нет данных о калориях без ручного ввода,
   противоречит принципу минимума действий. Не решать самостоятельно, если не попросят.
4. ⏸ Nutrition/КБЖУ — целенаправленно не трогается ни в одной из текущих фаз.
5. ⏸ Виджеты на главный экран — не в текущем скоупе.
