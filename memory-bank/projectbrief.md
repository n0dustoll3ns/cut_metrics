# Project Brief — Cut Metrics

## Что это

Cut Metrics — мобильное приложение (Flutter, Android → в перспективе iOS), которое собирает
данные пользователя из Health Connect (вес, сон, шаги), отделяет реальный тренд веса от шумовых
ежедневных колебаний и раз в неделю выдаёт короткое саммари с рекомендацией по корректировке
калорийности.

## Проблема

Пользователи, уже ведущие трекинг питания (MyFitnessPal и аналоги), не получают понятного темпа
изменения веса в % за неделю и понятного решения "что делать дальше". Вместо этого — таблицы
вручную или догадки.

## Целевая аудитория

18–50 лет, сидячая офисная работа, уже используют трекер калорий (это предпосылка использования
Cut Metrics, не альтернатива), осознанно проходят фазу "сушки"/работы над композицией тела.

## Ключевой принцип (критичен для архитектуры)

Минимум действий со стороны пользователя, максимум автоматизации. Любая фича, требующая лишнего
ручного ввода, — под вопросом и требует отдельного обоснования.

## Ядро продукта

Сглаживание сырых значений веса через EMA → расчёт фактического темпа изменения веса в % за
неделю → сравнение с целевым темпом пользователя (0.3–1.4%/нед, один из 2–3 пресетов) → статус
(в темпе / слишком медленно / слишком быстро) → 1–2 предложения рекомендации.

## Ограничения разработки

Один разработчик, ~10 часов в неделю, без отрыва от основной работы — архитектура должна быть
простой в поддержке, без избыточного инжиниринга. Это ключевой фильтр для любых архитектурных
решений в проекте.
